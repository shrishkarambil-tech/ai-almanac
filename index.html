05 Best AI for school, college & work

      
Three points each — the short version, not the sales pitch.


      

        

          
School students

          
    
            
  • Start with Gemini or ChatGPT free tiers — safe defaults with content guardrails.
    • 
            
  • Use AI to check understanding and get explained examples, not to write finished homework.
    • 
            
  • Ask "explain this three ways" instead of "give me the answer" to actually learn the material.
    • 
          

        

        

          
College students

          
    
            
  • Claude or ChatGPT for essays, problem sets and study guides; Perplexity for sourced research.
    • 
            
  • GitHub Copilot or Claude for CS coursework and side projects.
    • 
            
  • Check your institution's AI-use policy before submitting anything AI-assisted.
    • 
          

        

        

          
Working professionals

          
    
            
  • Developers: an in-editor tool (Copilot) plus a strong generalist (Claude) for design decisions.
    • 
            
  • Designers & video: a dedicated model (Midjourney, Veo, Runway) — generalists aren't built for this.
    • 
            
  • Business, marketing & research: a fast generalist (ChatGPT, Gemini) wired into your existing tools.

                  09 Security & how this site is built
                  
        
                    
          
                  • This is a static site — plain HTML, CSS and JavaScript with no server, no database and no login. There's no account data to leak because none is collected.
                    • 
          
                  • All content and ratings live in one readable file (data.js) — nothing is hidden, fetched from a third party, or executed remotely.
                    • 
          
                  • No cookies, no analytics, no forms sending data anywhere. What happens in your browser stays in your browser.
                    • 
        
                  
      
                  
      
                  
        
                  To publish this live
                  
        
                    
          
                  1. Keep index.html, style.css, data.js and script.js in one folder.
                    2. 
          
                  2. Push that folder to a GitHub repository.
                    3. 
          
                  3. Turn on GitHub Pages (or drag the folder into Netlify or Vercel) for a free, HTTPS-secured live URL.
                    4. 
          
                  4. To edit later: change the text in data.js and re-deploy — no rebuild step needed.
